## 🚀 How to Deploy on GitHub Pages
1. Push this entire folder to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Deploy Saurabh Pigeon Net website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository settings, go to **Pages** > **Build and deployment**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your website will be live at `https://<your-username>.github.io/<your-repo-name>/`.
